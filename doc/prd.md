# PRD (Product Requirements Document)

## 스마트 도서관 무인 키오스크 시뮬레이터

---

## 1. 제품 개요

### 1.1 제품명
스마트 도서관 무인 대출/반납 키오스크 시뮬레이터

### 1.2 제품 비전
ECO(이씨오) 사의 실제 무인 도서 대출/반납기의 화면과 동작을 충실하게 재현한 웹 기반 시뮬레이터. 공공도서관 이용자(특히 시니어)가 무인기기를 자유롭게 연습할 수 있는 학습 환경을 제공한다.

### 1.3 참조 제품
- **ECO(이씨오) 무인 도서 대출/반납기**: http://www.eco.co.kr/autoLib.html
- 화면 구성, 버튼 배치, 플로우 순서를 ECO 실제 제품과 동일하게 구현

### 1.4 대상 사용자
| 사용자 유형 | 설명 |
|---|---|
| 시니어 이용자 (65세+) | 도서관 무인기기 사용이 익숙하지 않은 주요 대상 |
| 일반 이용자 | 무인기기 사용법을 미리 연습하고자 하는 이용자 |
| 도서관 직원 | 신규 이용자 교육용 시뮬레이터로 활용 |
| 관리자 | 시뮬레이터 동작 확인 및 설정 변경 |

## 2. 기능 요구사항

### 2.1 핵심 기능 (P0 — 반드시 구현)

| ID | 기능명 | 설명 | 수용 기준 |
|---|---|---|---|
| F-001 | 대기 화면 | 키오스크 미사용 시 대기(Idle) 화면 표시. 터치 시 메인 메뉴 진입 | 터치 후 0.5초 이내 메뉴 전환 |
| F-002 | 메인 메뉴 | "도서 대출" / "도서 반납" 2개 버튼 표시. ECO 실제 화면과 동일한 레이아웃 | 버튼 크기 80px 이상, 터치 영역 확보 |
| F-003 | RFID 회원증 인증 | 회원증 태그 시뮬레이션. 2초 내 자동 인식 → PIN 입력 화면 전환 | 자동 인식 타임아웃 2초 |
| F-004 | PIN 번호 입력 | 4자리 숫자 키패드 입력. 4자리 완성 시 자동 제출 | 숫자 외 입력 불가, 자동 제출 |
| F-005 | 도서 대출 — 도서 선택 | 검색, 카테고리 필터, 도서 목록 그리드 표시 | **최대 2권 선택** 제한 |
| F-006 | 도서 대출 — 확인 | 선택 도서 목록, 대출자 정보, 반납예정일 표시 후 최종 확인 | 대출 완료 시 재고 감소 |
| F-007 | 도서 대출 — 완료 | 대출 성공 안내, 대출 통계 대시보드 표시 | 3초 후 자동 대기 복귀 또는 수동 |
| F-008 | 도서 반납 — 도서 투입 | 반납구 슬롯 시뮬레이션. 도서 자동 감지 | 2초 내 자동 감지 |
| F-009 | 도서 반납 — 스캔 | RFID 스캔 애니메이션, 감지 도서 목록, 추가 투입 옵션 | "더 넣기" 버튼으로 추가 반납 가능 |
| F-010 | 도서 반납 — 확인 | 반납 도서 목록 최종 확인 | 반납 완료 시 재고 증가 |
| F-011 | 도서 반납 — 완료 | 반납 성공 안내 | 대기 화면 자동 복귀 |

### 2.2 대출 규칙 (P0 — 정책 요구사항)

| 규칙 | 값 | 설명 |
|---|---|---|
| 최대 대출 권수 | **2권** | 1회 대출 시 최대 2권까지만 대출 가능 |
| 대출 기간 | **15일** | 대출일로부터 15일 후 반납 예정 |
| 연장 | **불가** | 대출 연장은 지원하지 않음 (API 400 응답) |
| 연체 제재 | **동일일수 차단** | 연체일수 × 1 = 차단일수 |

## 4. 사용자 스토리

### 4.1 대출 플로우

```
[시니어 이용자]로서 나는
  1. 대기 화면을 터치하여 시작하고 싶다
  2. "도서 대출"을 선택하여 대출 모드로 진입하고 싶다
  3. 회원증을 태그하여 내 계정을 인증받고 싶다
  4. PIN 번호를 입력하여 신원을 확인받고 싶다
  5. 원하는 도서를 검색/선택하고 싶다 (최대 2권)
  6. 대출 정보를 확인하고 최종 승인하고 싶다
  7. 대출 완료 안내를 확인하고 싶다
```

### 4.2 반납 플로우

```
[시니어 이용자]로서 나는
  1. 대기 화면을 터치하여 시작하고 싶다
  2. "도서 반납"을 선택하여 반납 모드로 진입하고 싶다
  3. 반납구에 도서를 투입하고 싶다
  4. 스캔 결과를 확인하고 추가 도서를 더 넣고 싶다
  5. 반납 정보를 확인하고 최종 승인하고 싶다
  6. 반납 완료 안내를 확인하고 싶다
```

## 6. 제약 사항

1. **최대 대출 2권** — ECO 실제 기기 정책과 동일. 3권 이상 선택 시 UI 차단
2. **연장 불가** — 대출 연장 API는 항상 400 반환
3. **세로 화면** — 키오스크 하드웨어가 세로 방향
4. **단일 페이지** — Next.js 파일시스템 라우팅 미사용, Zustand 기반 화면 전환
5. **오프라인 미지원** — Service Worker 현재 비활성화 (sw.js.disabled)
6. **단일 포트** — Next.js 3000번 포트만 외부 노출
