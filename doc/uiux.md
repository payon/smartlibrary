# UI/UX Design Document

## 스마트 도서관 무인 키오스크 시뮬레이터 — UI/UX 설계

---

## 1. 디자인 원칙

### 1.1 핵심 원칙

| 원칙 | 설명 |
|---|---|
| **ECO 화면 재현** | 이씨오 실제 무인기 화면 레이아웃, 색상, 버튼 배치를 충실히 재현 |
| **시니어 친화적** | 큰 글씨, 큰 버튼, 명확한 시각 피드백, 음성 안내 |
| **터치 우선** | 모든 인터랙션은 터치 기반, 최소 44px 터치 타겟 |
| **세로 화면** | 키오스크 하드웨어 세로 방향 (768×1024 기준) |
| **단순한 플로우** | 최소 단계, 되돌아가기 명확, 진행 상태 가시 |

### 1.2 시니어 UX 가이드라인

| 항목 | 기준 | 근거 |
|---|---|---|
| 최소 폰트 크기 | 18px | 65세+ 가독성 |
| 버튼 최소 높이 | 56px | 터치 정확도 |
| 버튼 간격 | 16px 이상 | 오타 방지 |
| 대비비 | 4.5:1 이상 | WCAG AA |
| 응답 시간 | 200ms 이내 | 체감 반응성 |
| 타임아웃 | 30초 (자동 대기 복귀) | 유휴 관리 |

## 5. 애니메이션 설계

### 5.1 화면 전환

| 애니메이션 | 지속 | 이징 | 설명 |
|---|---|---|---|
| 페이드 인/아웃 | 300ms | ease-in-out | 기본 화면 전환 |
| 슬라이드 (선택) | 300ms | ease-out | 하위 화면 진입 |

### 5.2 인터랙션 애니메이션

| 애니메이션 | 키프레임 | 용도 |
|---|---|---|
| `sensorPulse` | scale 1→1.05→1 | 센서 활성 표시 |
| `scanRFID` | opacity 0.3→1, scale 0.8→1 | RFID 스캔 펄스 |
| `cardScanRing` | scale 0→1.5, opacity 1→0 | 카드 스캔 동심원 |
| `successCheck` | scale 0→1.2→1 | 성공 체크마크 |
| `insertBook` | translateY -20→0 | 도서 투입 슬롯 |
| `glow` | boxShadow 확장/수축 | 대기 화면 글로우 |

### 5.3 시니어 모션 프리퍼런스

```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; }
}
```

## 6. 레이아웃 시스템

### 6.1 키오스크 프레임

```css
.kiosk-frame {
  max-width: 480px;      /* 모바일 키오스크 폭 */
  margin: 0 auto;        /* 중앙 정렬 */
  min-height: 100vh;     /* 전체 높이 */
  position: relative;
  overflow: hidden;
}

.kiosk-screen {
  padding: 24px;         /* 화면 내 여백 */
  min-height: 100vh;
}
```

### 6.2 반응형 브레이크포인트

| 이름 | 폭 | 용도 |
|---|---|---|
| 기본 | <640px | 모바일/키오스크 |
| sm | ≥640px | — |
| md | ≥768px | 태블릿 |
| lg | ≥1024px | 데스크톱 (디버그) |

### 6.3 그리드 시스템

- 도서 목록: 2열 그리드 (`grid-cols-2`)
- PIN 키패드: 3열 그리드 (`grid-cols-3`)
- 카테고리 탭: 가로 스크롤 (`flex overflow-x-auto`)
- 통계 카드: 3열 그리드 (`grid-cols-3`)

## 7. 접근성 설계

### 7.1 ARIA 속성

| 요소 | 속성 | 값 |
|---|---|---|
| 키오스크 프레임 | `role` | `application` |
| 화면 컨테이너 | `aria-live` | `polite` |
| PIN 입력 | `aria-label` | `"PIN 번호 입력"` |
| 도서 카드 | `aria-label` | `"도서: {title}"` |
| 선택 카운트 | `aria-live` | `assertive` |

### 7.2 포커스 관리

- 화면 전환 시 첫 번째 인터랙티브 요소에 자동 포커스
- 모달/오버레이 포커스 트랩
- 뒤로 가기 시 이전 포커스 복원

### 7.3 스크린 리더

- 화면 전환 안내: "도서 선택 화면입니다"
- 성공/오류 메시지: `aria-live` 영역
- 시각 전용 요소: `aria-hidden="true"`
