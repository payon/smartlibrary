     1→# 관리자 대시보드 API 명세서
     2→
     3→> 한국 스마트 도서관 키오스크 관리자 대시보드 API Specification

     6→> 모든 관리자 API는 `/api/admin/*` 경로에 위치하며, JWT 인증 및 RBAC 권한 검사가 필요합니다.

    27→## 1. 공통 사항
    28→
    29→### 1.1 인증 헤더
    30→
    31→모든 `/api/admin/*` 엔드포인트는 아래 헤더가 필수입니다:
    32→
    33→```
    34→Authorization: Bearer {JWT}
    35→```
    36→
    37→JWT가 누락되거나 만료된 경우 `401 Unauthorized` 응답이 반환됩니다.
    38→
    39→### 1.2 RBAC 권한 체계
    40→
    41→| Role | Code | 설명 |
    42→|------|------|------|
    43→| Super Admin | `super_admin` | 모든 권한, 관리자 계정 관리 가능 |
    44→| Admin | `admin` | 콘텐츠/도서/사용자/공지/설정 관리 가능 |
    45→| Viewer | `viewer` | 읽기 전용, 통계/로그 조회만 가능 |
    46→
    47→권한이 부족한 경우 `403 Forbidden` 응답이 반환됩니다.
    48→
    49→### 1.3 공통 에러 응답 형식
    50→
    51→모든 에러 응답은 아래 JSON 구조를 따릅니다:
    52→
    53→```json
    54→{
    55→  "error": {
    56→    "code": "ERROR_CODE",
    57→    "message": "사람이 읽을 수 있는 에러 메시지",
    58→    "details": {}
    59→  }
    60→}
    61→```
    62→
    63→### 1.4 공통 HTTP 상태 코드
    64→
    65→| Status | Code | 설명 |
    66→|--------|------|------|
    67→| 400 | `BAD_REQUEST` | 잘못된 요청 파라미터 또는 본문 |
    68→| 401 | `UNAUTHORIZED` | JWT 누락, 만료 또는 무효 |
    69→| 403 | `FORBIDDEN` | 권한 부족 (RBAC 거부) |
    70→| 404 | `NOT_FOUND` | 요청한 리소스가 존재하지 않음 |
    71→| 409 | `CONFLICT` | 중복 리소스 (예: 이미 존재하는 이메일) |
    72→| 429 | `RATE_LIMITED` | 요청 한도 초과 |
    73→| 500 | `INTERNAL_ERROR` | 서버 내부 오류 |
    74→
    75→### 1.5 Rate Limiting
    76→
    77→| 대상 | 한도 | Window |
    78→|------|------|--------|
    79→| 인증 API (`/auth/*`) | 10회 | 1분 |
    80→| 일반 관리자 API | 100회 | 1분 |
    81→| 이미지 업로드 | 20회 | 1분 |
    82→| 공개 CMS API (`/api/cms/*`) | 200회 | 1분 |
    83→
    84→Rate limit 초과 시:
    85→
    86→```
    87→HTTP/1.1 429 Too Many Requests
    88→X-RateLimit-Limit: 100
    89→X-RateLimit-Remaining: 0
    90→X-RateLimit-Reset: 1719500400
    91→```
    92→
    93→```json
    94→{
    95→  "error": {
    96→    "code": "RATE_LIMITED",
    97→    "message": "요청 한도를 초과했습니다. 잠시 후 다시 시도해주세요.",
    98→    "details": {
    99→      "limit": 100,
   100→      "window": "60s",
   101→      "resetAt": "2025-06-27T15:00:00Z"
   102→    }
   103→  }
   104→}
   105→```
   106→
   107→### 1.6 공통 쿼리 파라미터 (Pagination)
   108→
   109→| Parameter | Type | Default | 설명 |
   110→|-----------|------|---------|------|
   111→| `page` | integer | 1 | 페이지 번호 (1-based) |
   112→| `limit` | integer | 20 | 페이지당 항목 수 (max: 100) |
   113→| `sortBy` | string | `createdAt` | 정렬 필드 |
   114→| `sortOrder` | string | `desc` | 정렬 방향 (`asc` / `desc`) |
   115→
   116→Pagination 응답 형식:
   117→
   118→```json
   119→{
   120→  "data": [],
   121→  "pagination": {
   122→    "page": 1,
   123→    "limit": 20,
   124→    "total": 150,
   125→    "totalPages": 8
   126→  }
   127→}
   128→```
   129→
   130→### 1.7 공통 응답 헤더
   131→
   132→```
   133→X-Request-Id: {uuid}
   134→X-RateLimit-Limit: {limit}
   135→X-RateLimit-Remaining: {remaining}
   136→X-RateLimit-Reset: {epoch}
   137→```

   141→## 2. 인증 API
   142→
   143→### 2.1 로그인
   144→
   145→```
   146→POST /api/admin/auth/login
   147→```
   148→
   149→- **Required Role**: 없음 (공개 엔드포인트)
   150→- **Rate Limit**: 10회/1분
   151→
   152→**Request Body:**
   153→
   154→```json
   155→{
   156→  "email": "admin@library.go.kr",
   157→  "password": "SecureP@ss123!"
   158→}
   159→```
   160→
   161→| Field | Type | Required | Validation |
   162→|-------|------|----------|------------|
   163→| `email` | string | ✅ | 유효한 이메일 형식 |
   164→| `password` | string | ✅ | 최소 8자 |
   165→
   166→**Response 200:**
   167→
   168→```json
   169→{
   170→  "data": {
   171→    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
   172→    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
   173→    "expiresIn": 3600,
   174→    "admin": {
   175→      "id": "adm_01HX3K8M2P",
   176→      "email": "admin@library.go.kr",
   177→      "name": "김관리",
   178→      "role": "admin",
   179→      "lastLoginAt": "2025-06-27T14:30:00Z"
   180→    }
   181→  }
   182→}
   183→```
   184→
   185→**Error 400:**
   186→
   187→```json
   188→{
   189→  "error": {
   190→    "code": "VALIDATION_ERROR",
   191→    "message": "요청 본문이 올바르지 않습니다.",
   192→    "details": {
   193→      "email": "유효한 이메일 주소를 입력해주세요.",
   194→      "password": "비밀번호는 최소 8자 이상이어야 합니다."
   195→    }
   196→  }
   197→}
   198→```
   199→
   200→**Error 401:**
   201→
   202→```json
   203→{
   204→  "error": {
   205→    "code": "INVALID_CREDENTIALS",
   206→    "message": "이메일 또는 비밀번호가 올바르지 않습니다.",
   207→    "details": {}
   208→  }
   209→}
   210→```
   211→
   212→**Error 429:**
   213→
   214→```json
   215→{
   216→  "error": {
   217→    "code": "RATE_LIMITED",
   218→    "message": "로그인 시도가 너무 많습니다. 5분 후 다시 시도해주세요.",
   219→    "details": {
   220→      "retryAfter": 300
   221→    }
   222→  }
   223→}
   224→```

   228→### 2.2 로그아웃
   229→
   230→```
   231→POST /api/admin/auth/logout
   232→```
   233→
   234→- **Required Role**: `viewer` 이상 (인증 필요)
   235→- **Description**: 현재 세션의 refreshToken을 무효화합니다.
   236→
   237→**Request Headers:**
   238→
   239→```
   240→Authorization: Bearer {JWT}
   241→```
   242→
   243→**Request Body:**
   244→
   245→```json
   246→{
   247→  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
   248→}
   249→```
   250→
   251→| Field | Type | Required | 설명 |
   252→|-------|------|----------|------|
   253→| `refreshToken` | string | ✅ | 무효화할 refresh token |
   254→
   255→**Response 200:**
   256→
   257→```json
   258→{
   259→  "data": {
   260→    "message": "로그아웃 되었습니다."
   261→  }
   262→}
   263→```
   264→
   265→**Error 401:**
   266→
   267→```json
   268→{
   269→  "error": {
   270→    "code": "UNAUTHORIZED",
   271→    "message": "인증이 필요합니다.",
   272→    "details": {}
   273→  }
   274→}
   275→```

   332→## 3. CMS 콘텐츠 API
   333→
   334→### 3.1 콘텐츠 목록 조회
   335→
   336→```
   337→GET /api/admin/cms

   489→
   490→```
   491→PUT /api/admin/cms/[key]
   492→```

   498→

   502→}
   503→```

   507→| `value` | string | ✅ | 새로운 콘텐츠 값 (빈 문자열 허용, max: 2000자) |
   508→
   509→**Response 200:**
   510→
   511→```json
   512→{
   513→  "data": {
   514→    "key": "main.title",
   515→    "label": "메인 화면 제목",

   574→### 3.4 콘텐츠 일괄 수정
   575→
   576→```
   577→POST /api/admin/cms/batch
   578→```
   579→
   580→- **Required Role**: `admin` 이상
   581→- **Description**: 여러 콘텐츠 항목을 한 번에 수정합니다. 각 변경마다 감사 로그가 개별적으로 기록됩니다.
   582→
   583→**Request Body:**
   584→
   585→```json
   586→{
   587→  "items": [
   588→    {
   589→      "key": "main.title",
   590→      "value": "행복한 도서관에 오신 것을 환영합니다"
   591→    },
