    27→    27→## 1. 공통 사항
    28→    28→
    29→    29→### 1.1 인증 헤더
    30→    30→
    31→    31→모든 `/api/admin/*` 엔드포인트는 아래 헤더가 필수입니다:
    32→    32→
    33→    33→```
    34→    34→Authorization: Bearer {JWT}
    35→    35→```
    36→    36→
    37→    37→JWT가 누락되거나 만료된 경우 `401 Unauthorized` 응답이 반환됩니다.
    38→    38→
    39→    39→### 1.2 RBAC 권한 체계
    40→    40→
    41→    41→| Role | Code | 설명 |
    42→    42→|------|------|------|
    43→    43→| Super Admin | `super_admin` | 모든 권한, 관리자 계정 관리 가능 |
    44→    44→| Admin | `admin` | 콘텐츠/도서/사용자/공지/설정 관리 가능 |
    45→    45→| Viewer | `viewer` | 읽기 전용, 통계/로그 조회만 가능 |
    46→    46→
    47→    47→권한이 부족한 경우 `403 Forbidden` 응답이 반환됩니다.
    48→    48→
    49→    49→### 1.3 공통 에러 응답 형식
    50→    50→
    51→    51→모든 에러 응답은 아래 JSON 구조를 따릅니다:
    52→    52→
    53→    53→```json
    54→    54→{
    55→    55→  "error": {
    56→    56→    "code": "ERROR_CODE",
    57→    57→    "message": "사람이 읽을 수 있는 에러 메시지",
    58→    58→    "details": {}
    59→    59→  }
    60→    60→}
    61→    61→```
    62→    62→
    63→    63→### 1.4 공통 HTTP 상태 코드
    64→    64→
    65→    65→| Status | Code | 설명 |
    66→    66→|--------|------|------|
    67→    67→| 400 | `BAD_REQUEST` | 잘못된 요청 파라미터 또는 본문 |
    68→    68→| 401 | `UNAUTHORIZED` | JWT 누락, 만료 또는 무효 |
    69→    69→| 403 | `FORBIDDEN` | 권한 부족 (RBAC 거부) |
    70→    70→| 404 | `NOT_FOUND` | 요청한 리소스가 존재하지 않음 |
    71→    71→| 409 | `CONFLICT` | 중복 리소스 (예: 이미 존재하는 이메일) |
    72→    72→| 429 | `RATE_LIMITED` | 요청 한도 초과 |
    73→    73→| 500 | `INTERNAL_ERROR` | 서버 내부 오류 |
    74→    74→
    75→    75→### 1.5 Rate Limiting
    76→    76→
    77→    77→| 대상 | 한도 | Window |
    78→    78→|------|------|--------|
    79→    79→| 인증 API (`/auth/*`) | 10회 | 1분 |
    80→    80→| 일반 관리자 API | 100회 | 1분 |
    81→    81→| 이미지 업로드 | 20회 | 1분 |
    82→    82→| 공개 CMS API (`/api/cms/*`) | 200회 | 1분 |
    83→    83→
    84→    84→Rate limit 초과 시:
    85→    85→
    86→    86→```
    87→    87→HTTP/1.1 429 Too Many Requests
    88→    88→X-RateLimit-Limit: 100
    89→    89→X-RateLimit-Remaining: 0
    90→    90→X-RateLimit-Reset: 1719500400
    91→    91→```
    92→    92→
    93→    93→```json
    94→    94→{
    95→    95→  "error": {
    96→    96→    "code": "RATE_LIMITED",
    97→    97→    "message": "요청 한도를 초과했습니다. 잠시 후 다시 시도해주세요.",
    98→    98→    "details": {
    99→    99→      "limit": 100,
   100→   100→      "window": "60s",
   101→   101→      "resetAt": "2025-06-27T15:00:00Z"
   102→   102→    }
   103→   103→  }
   104→   104→}
   105→   105→```
   106→   106→
   107→   107→### 1.6 공통 쿼리 파라미터 (Pagination)
   108→   108→
   109→   109→| Parameter | Type | Default | 설명 |
   110→   110→|-----------|------|---------|------|
   111→   111→| `page` | integer | 1 | 페이지 번호 (1-based) |
   112→   112→| `limit` | integer | 20 | 페이지당 항목 수 (max: 100) |
   113→   113→| `sortBy` | string | `createdAt` | 정렬 필드 |
   114→   114→| `sortOrder` | string | `desc` | 정렬 방향 (`asc` / `desc`) |
   115→   115→
   116→   116→Pagination 응답 형식:
   117→   117→
   118→   118→```json
   119→   119→{
   120→   120→  "data": [],
   121→   121→  "pagination": {
   122→   122→    "page": 1,
   123→   123→    "limit": 20,
   124→   124→    "total": 150,
   125→   125→    "totalPages": 8
   126→   126→  }
   127→   127→}
   128→   128→```
   129→   129→
   130→   130→### 1.7 공통 응답 헤더
   131→   131→
   132→   132→```
   133→   133→X-Request-Id: {uuid}
   134→   134→X-RateLimit-Limit: {limit}
   135→   135→X-RateLimit-Remaining: {remaining}
   136→   136→X-RateLimit-Reset: {epoch}
   137→   137→```

   152→   152→**Request Body:**
   153→   153→
   154→   154→```json

   942→   942→## 5. 공개 CMS API (키오스크에서 호출, 인증 불필요)
   943→   943→
   944→   944→> 키오스크 클라이언트에서 호출하는 공개 API입니다.  
   945→   945→> JWT 인증이 필요하지 않으며, 응답 캐싱을 위해 ETag / If-None-Match 헤더를 지원합니다.
   946→   946→
   947→   947→### 5.1 전체 콘텐츠 조회
   948→   948→
   949→   949→```
   950→   950→GET /api/cms/content
   951→   951→```
   952→   952→
   953→   953→- **Required Role**: 없음 (공개)
   954→   954→- **Cache**: ETag 지원, max-age=300 (5분)
   955→   955→
   956→   956→**Query Parameters:**
   957→   957→
   958→   958→| Parameter | Type | Required | 설명 |
   959→   959→|-----------|------|----------|------|
   960→   960→| `v` | integer | ❌ | 콘텐츠 버전 (변경 시에만 응답 반환, 아니면 304) |
   961→   961→
   962→   962→**Request Headers (조건부 요청):**
   963→   963→
   964→   964→```
   965→   965→If-None-Match: "etag_abc123"
   966→   966→```
   967→   967→
   968→   968→**Response 200:**
   969→   969→
   970→   970→```
   971→   971→ETag: "etag_def456"
   972→   972→Cache-Control: public, max-age=300
