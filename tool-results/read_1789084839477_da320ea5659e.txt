   435→   435→   435→### 4.1 인증 흐름 다이어그램
   436→   436→   436→
   437→   437→   437→```
   438→   438→   438→┌──────────────┐                                           ┌──────────────────┐
   439→   439→   439→│  /admin/login│                                           │  AdminUser Table  │
   440→   440→   440→│  (이메일 +   │                                           │  email            │
   441→   441→   441→│   비밀번호    │                                           │  passwordHash     │
   442→   442→   442→│   입력 폼)   │                                           │  role             │
   443→   443→   443→└──────┬───────┘                                           │  isActive         │
   444→   444→   444→       │ POST /api/admin/auth/login                        └────────┬─────────┘
   445→   445→   445→       │ { email, password }                                        │
   446→   446→   446→       ▼                                                            │
   447→   447→   447→┌──────────────────────────────────────────────────────────────────┤
   448→   448→   448→│  ① 이메일로 AdminUser 조회                                       │
   449→   449→   449→│  ② bcrypt.compare(password, passwordHash) 검증                   │
   450→   450→   450→│  ③ isActive === true 확인                                        │
   451→   451→   451→│  ④ 로그인 실패 횟수 확인 (5회 초과 시 15분 잠금)                  │
   452→   452→   452→│  ⑤ JWT Access Token + Refresh Token 발급                         │
   453→   453→   453→│  ⑥ httpOnly 쿠키에 토큰 저장                                     │
   454→   454→   454→│  ⑦ lastLoginAt 갱신                                               │
   455→   455→   455→│  ⑧ AuditLog 기록 (LOGIN 이벤트)                                   │
   456→   456→   456→└──────────────────────────────────────────────────────────────────┘
   457→   457→   457→       │
   458→   458→   458→       ▼ 302 Redirect → /admin
   459→   459→   459→       Set-Cookie: admin_access_token=<jwt>; HttpOnly; Secure; SameSite=Strict; Path=/admin; Max-Age=900
   460→   460→   460→       Set-Cookie: admin_refresh_token=<jwt>; HttpOnly; Secure; SameSite=Strict; Path=/api/admin/auth; Max-Age=604800
   461→   461→   461→```
   462→   462→   462→
   463→   463→   463→### 4.2 JWT 토큰 구조
   464→   464→   464→
   465→   465→   465→```typescript
   466→   466→   466→// Access Token Payload
