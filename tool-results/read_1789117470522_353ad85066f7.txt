    31→## 1. 공통 사항
    32→
    33→### 1.1 인증 헤더
    34→
    35→모든 `/api/admin/*` 엔드포인트는 아래 헤더가 필수입니다 (인증 API 제외):
    36→
    37→```
    38→Authorization: Bearer {JWT}
    39→```
    40→
    41→JWT가 누락되거나 만료된 경우 `401 Unauthorized` 응답이 반환됩니다.
    42→
    43→### 1.2 RBAC 권한 체계
    44→
    45→| Role | Code | 설명 |
    46→|------|------|------|
    47→| Super Admin | `super_admin` | 모든 권한, 관리자 계정 관리 및 시스템 설정 가능 |
    48→| Admin | `admin` | 콘텐츠/도서/이용자/알림 관리 가능, 설정 읽기 가능 |
    49→| Viewer | `viewer` | 읽기 전용, 통계/로그/콘텐츠 조회만 가능 |
    50→
    51→권한이 부족한 경우 `403 Forbidden` 응답이 반환됩니다.
    52→
    53→### 1.3 공통 에러 응답 형식
    54→
    55→모든 에러 응답은 아래 JSON 구조를 따릅니다:
    56→
    57→```json
    58→{
    59→  "error": {
    60→    "code": "ERROR_CODE",
    61→    "message": "사람이 읽을 수 있는 에러 메시지",
    62→    "details": {}
    63→  }
    64→}
    65→```
    66→
    67→### 1.4 공통 HTTP 상태 코드
    68→
    69→| Status | Code | 설명 |
    70→|--------|------|------|
    71→| 400 | `BAD_REQUEST` | 잘못된 요청 파라미터 또는 본문 |
    72→| 401 | `UNAUTHORIZED` | JWT 누락, 만료 또는 무효 |
    73→| 403 | `FORBIDDEN` | 권한 부족 (RBAC 거부) |
    74→| 404 | `NOT_FOUND` | 요청한 리소스가 존재하지 않음 |
    75→| 409 | `CONFLICT` | 중복 리소스 (예: 이미 존재하는 이메일) |
    76→| 422 | `VALIDATION_ERROR` | 요청 본문 유효성 검사 실패 |
    77→| 429 | `RATE_LIMITED` | 요청 한도 초과 |
    78→| 500 | `INTERNAL_ERROR` | 서버 내부 오류 |
    79→
    80→### 1.5 공통 쿼리 파라미터 (Pagination)
    81→
    82→| Parameter | Type | Default | 설명 |
    83→|-----------|------|---------|------|
    84→| `page` | integer | 1 | 페이지 번호 (1-based) |
    85→| `limit` | integer | 20 | 페이지당 항목 수 (max: 100) |
    86→| `sortBy` | string | `createdAt` | 정렬 필드 |
    87→| `sortOrder` | string | `desc` | 정렬 방향 (`asc` / `desc`) |
    88→
    89→Pagination 응답 형식:
    90→
    91→```json
    92→{
    93→  "data": [],
    94→  "pagination": {
    95→    "page": 1,
    96→    "limit": 20,
    97→    "total": 150,
    98→    "totalPages": 8
    99→  }
   100→}
   101→```
   102→
   103→### 1.6 공통 응답 헤더
   104→
   105→```
   106→Content-Type: application/json
   107→X-Request-Id: {uuid}
   108→X-RateLimit-Limit: {limit}
   109→X-RateLimit-Remaining: {remaining}
   110→X-RateLimit-Reset: {epoch}
   111→X-Frame-Options: DENY
   112→X-Content-Type-Options: nosniff
   113→Content-Security-Policy: default-src 'self'
   114→Strict-Transport-Security: max-age=31536000
   115→```
   116→
   117→### 1.7 요청 본문 크기 제한
   118→
   119→| 대상 | 최대 크기 |
   120→|------|-----------|
   121→| 일반 JSON 요청 | 1MB |
   122→| 이미지 업로드 (`/api/admin/media/upload`) | 10MB |
   123→| CSV 가져오기 (`/api/admin/books/import`) | 5MB |

   127→## 2. Admin 인증 API
   128→
   129→### 2.1 로그인
   130→
   131→```
   132→POST /api/admin/auth/login
   133→```
   134→
   135→- **설명**: 관리자 이메일 및 비밀번호로 로그인하여 JWT를 발급받습니다.
   136→- **인증**: 불필요 (공개 엔드포인트)
   137→- **Rate Limit**: 10회/1분 (IP 기준)
   138→
   139→**요청 본문:**
   140→
   141→```json
   142→{
   143→  "email": "admin@library.go.kr",
   144→  "password": "SecureP@ss123!"
   145→}
   146→```
   147→
   148→| 필드 | 타입 | 필수 | 제약 | 설명 |
   149→|------|------|------|------|------|
   150→| `email` | string | ✅ | 유효한 이메일 형식 | 관리자 이메일 |
   151→| `password` | string | ✅ | 최소 8자, 영문+숫자+특수문자 포함 | 비밀번호 |
   152→
   153→**응답 200:**
   154→
   155→```json
   156→{
   157→  "data": {
   158→    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
   159→    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
   160→    "expiresIn": 3600,
   161→    "admin": {
   162→      "id": "adm_01HX3K8M2P",
   163→      "email": "admin@library.go.kr",
   164→      "name": "김관리",
   165→      "role": "admin",
   166→      "lastLoginAt": "2025-06-27T14:30:00Z"
   167→    }
   168→  }
   169→}
   170→```
   171→
   172→**오류 400 — 유효성 오류:**
   173→
   174→```json
   175→{
   176→  "error": {
   177→    "code": "VALIDATION_ERROR",
   178→    "message": "요청 본문이 올바르지 않습니다.",
   179→    "details": {
   180→      "email": "유효한 이메일 주소를 입력해주세요.",
   181→      "password": "비밀번호는 최소 8자 이상이어야 합니다."
   182→    }
   183→  }
   184→}
   185→```
   186→
   187→**오류 401 — 자격 증명 불일치:**
   188→
   189→```json
   190→{
   191→  "error": {
   192→    "code": "INVALID_CREDENTIALS",
   193→    "message": "이메일 또는 비밀번호가 올바르지 않습니다.",
   194→    "details": {}
   195→  }
   196→}
   197→```
   198→
   199→**오류 429 — 시도 초과:**
   200→
   201→```json
   202→{
   203→  "error": {
   204→    "code": "RATE_LIMITED",
   205→    "message": "로그인 시도가 너무 많습니다. 5분 후 다시 시도해주세요.",
   206→    "details": {
   207→      "retryAfter": 300
   208→    }
   209→  }
   210→}
   211→```

   215→### 2.2 로그아웃
   216→

   223→- **Rate Limit**: 20회/1분
   224→
   225→**요청 본문:**
   226→
   227→```json
   228→{
   229→  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

   231→```
   232→
   233→| 필드 | 타입 | 필수 | 설명 |
   234→|------|------|------|------|
   235→| `refreshToken` | string | ✅ | 무효화할 refresh token |
   236→
   237→**응답 200:**
   238→
   239→```json
   240→{
   241→  "data": {
   242→    "message": "로그아웃 되었습니다."
   243→  }
   244→}

   316→### 2.4 비밀번호 변경
   317→
   318→```
   319→POST /api/admin/auth/change-password
   320→```
   321→
   322→- **설명**: 현재 비밀번호를 확인한 후 새 비밀번호로 변경합니다.
   323→- **인증**: `viewer` 이상
   324→- **Rate Limit**: 5회/1분
   325→
   326→**요청 본문:**
   327→
   328→```json
   329→{
   330→  "currentPassword": "OldP@ss123!",
   331→  "newPassword": "NewP@ss456!",
   332→  "confirmPassword": "NewP@ss456!"
   333→}
   334→```
   335→
   336→| 필드 | 타입 | 필수 | 제약 | 설명 |
   337→|------|------|------|------|------|
   338→| `currentPassword` | string | ✅ | 최소 8자 | 현재 비밀번호 |
   339→| `newPassword` | string | ✅ | 최소 8자, 영문+숫자+특수문자 포함, currentPassword와 상이 | 새 비밀번호 |
   340→| `confirmPassword` | string | ✅ | newPassword와 일치 | 비밀번호 확인 |
   341→
   342→**응답 200:**
   343→
   344→```json
   345→{
   346→  "data": {
   347→    "message": "비밀번호가 변경되었습니다."
   348→  }
   349→}
   350→```
   351→
   352→**오류 400 — 유효성 오류:**
   353→
   354→```json
   355→{
   356→  "error": {
   357→    "code": "VALIDATION_ERROR",
   358→    "message": "요청 본문이 올바르지 않습니다.",
   359→    "details": {
   360→      "newPassword": "비밀번호는 영문, 숫자, 특수문자를 포함하여 8자 이상이어야 합니다.",
   361→      "confirmPassword": "비밀번호 확인이 일치하지 않습니다."
   362→    }
   363→  }
   364→}
   365→```
   366→
   367→**오류 401 — 현재 비밀번호 불일치:**
   368→
   369→```json
   370→{
   371→  "error": {
   372→    "code": "INVALID_CREDENTIALS",
   373→    "message": "현재 비밀번호가 올바르지 않습니다.",
   374→    "details": {}

   381→## 3. 콘텐츠 관리 API (CMS)
   382→
   383→### 3.1 콘텐츠 목록 조회
   384→
   385→```
   386→GET /api/admin/content
   387→```
   388→
   389→- **설명**: 모든 콘텐츠 항목을 조회합니다. 화면(screen) 및 타입(type)으로 필터링할 수 있습니다.
   390→- **인증**: `viewer` 이상
   391→- **Rate Limit**: 100회/1분
   392→
   393→**쿼리 파라미터:**
   394→
   395→| 파라미터 | 타입 | 필수 | 설명 |
   396→|-----------|------|------|------|
   397→| `screen` | string | ❌ | 화면 필터 (`main` / `search` / `return` / `info` / `notice`) |
   398→| `type` | string | ❌ | 타입 필터 (`text` / `image` / `color` / `icon`) |
   399→| `search` | string | ❌ | key 또는 label 검색어 |
   400→| `page` | integer | ❌ | 페이지 번호 (default: 1) |
   401→| `limit` | integer | ❌ | 페이지당 항목 수 (default: 50, max: 200) |
   402→
   403→**예시 요청:**
   404→
   405→```
   406→GET /api/admin/content?screen=main&type=text&limit=50
   407→```
   408→
   409→**응답 200:**
   410→
   411→```json
   412→{
   413→  "data": [
   414→    {
   415→      "key": "main.title",
   416→      "label": "메인 화면 제목",
   417→      "value": "스마트 도서관에 오신 것을 환영합니다",
   418→      "defaultValue": "스마트 도서관에 오신 것을 환영합니다",
   419→      "screen": "main",
   420→      "type": "text",
   421→      "version": 3,
   422→      "updatedAt": "2025-06-27T10:00:00Z",
   423→      "updatedBy": {
   424→        "id": "adm_01HX3K8M2P",
   425→        "name": "김관리"
   426→      }
   427→    },
   428→    {
   429→      "key": "main.background_image",
   430→      "label": "메인 배경 이미지",
   431→      "value": "/uploads/img_01HX3K9A7N.jpg",
   432→      "defaultValue": "/uploads/default_bg.jpg",
   433→      "screen": "main",
   434→      "type": "image",
   435→      "version": 1,
   436→      "updatedAt": "2025-06-20T12:00:00Z",
   437→      "updatedBy": {
   438→        "id": "adm_01HX3K8M2P",

   483→

   488→**응답 200:**
   489→

   492→  "data": {
   493→    "key": "main.title",

   496→    "defaultValue": "스마트 도서관에 오신 것을 환영합니다",
   497→    "screen": "main",
   498→    "type": "text",
   499→    "description": "키오스크 메인 화면 상단에 표시되는 제목 텍스트입니다.",

   501→    "updatedAt": "2025-06-27T10:00:00Z",
   502→    "updatedBy": {

   779→## 4. 공개 콘텐츠 API (키오스크용)
   780→
   781→> 이 API 그룹은 키오스크에서 호출하는 공개 엔드포인트로, 인증이 필요하지 않습니다.
   782→
   783→### 4.1 키오스크 콘텐츠 전체 조회
   784→
   785→```
   786→GET /api/content
   787→```
   788→
   789→- **설명**: 키오스크에서 사용할 전체 콘텐츠를 조회합니다. 화면별로 그룹화되어 반환됩니다.
   790→- **인증**: 불필요 (공개 엔드포인트)
   791→- **Rate Limit**: 200회/1분
   792→- **Cache**: `Cache-Control: public, max-age=60, s-maxage=300`
   793→
   794→**쿼리 파라미터:**
   795→
   796→| 파라미터 | 타입 | 필수 | 설명 |
   797→|-----------|------|------|------|
   798→| `screen` | string | ❌ | 특정 화면만 조회 (`main` / `search` / `return` / `info` / `notice`) |
   799→
   800→**응답 200:**
   801→
   802→```json
   803→{
   804→  "data": {
   805→    "main": {
   806→      "title": "스마트 도서관에 오신 것을 환영합니다",
   807→      "subtitle": "도서 검색과 대출/반납을 이용할 수 있습니다",
   808→      "background_image": "/uploads/img_01HX3K9A7N.jpg"
   809→    },
   810→    "search": {
   811→      "title": "도서 검색",
   812→      "placeholder": "도서명 또는 저자를 입력하세요"
   813→    },
   814→    "return": {
   815→      "title": "도서 반납",
   816→      "instruction": "반납할 도서를 아래에 놓아주세요"
   817→    },
   818→    "info": {
   819→      "title": "도서관 안내",
   820→      "operating_hours": "09:00 ~ 18:00"
   821→    }
   822→  },
   823→  "version": "a1b2c3d4",
   824→  "updatedAt": "2025-06-27T10:00:00Z"
   825→}
   826→```
   827→
   828→---
   829→
   830→### 4.2 콘텐츠 버전 해시 조회
   831→
   832→```
   833→GET /api/content/version
   834→```
   835→
   836→- **설명**: 현재 콘텐츠의 버전 해시를 반환합니다. 키오스크는 폴링으로 해시가 변경되었는지 확인 후 전체 콘텐츠를 다시 가져올 수 있습니다.
   837→- **인증**: 불필요 (공개 엔드포인트)
   838→- **Rate Limit**: 600회/1분 (10초 간격 폴링 지원)
   839→- **Cache**: `Cache-Control: public, max-age=10`
   840→
   841→**응답 200:**
   842→
   843→```json
   844→{
   845→  "data": {
   846→    "version": "a1b2c3d4",
   847→    "updatedAt": "2025-06-27T10:00:00Z"
   848→  }
   849→}
   850→```
   851→
   852→> **폴링 사용 예시**: 키오스크는 10초 간격으로 `GET /api/content/version`을 호출하여 `version` 해시를 비교합니다. 해시가 변경된 경우에만 `GET /api/content`를 호출하여 콘텐츠를 갱신합니다.
